# Mercado Piquiri Celeste 
Aplicação para gerenciar vendas no Mercado Piquiri Celeste.

## Contexto
O sistema do Mercadinho Piquiri Celeste gerencia clientes, compras, produtos e categorias. Cada cliente é identificado de forma única pelo CPF e realiza compras registradas com ID e data. Cada compra pode conter múltiplos produtos (registrando a quantidade de cada um) e possui o valor total calculado a partir dos itens. Os produtos possuem preço e classe, e cada um está associado a uma única categoria para melhor organização do catálogo.
